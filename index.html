RAG · Hybrid retrieval2026

PostgreSQL RAG Chat

A chat interface over live PostgreSQL tables that routes each question by intent: structured asks ("top 200 customers by revenue") are translated into read-only SQL and returned as a table, while semantic asks ("explain churn drivers") go through retrieval over chunked rows. Embeddings are stored in FAISS and re-indexed automatically when a table is added or row counts shift.

Guardrails are the interesting part: SELECT-only, single statement, enforced LIMIT, and a hard fallback that answers "I don't know based on the indexed data" when retrieval confidence is low.

NLP · Explainability2024

Fake News Detection with Explainable AI

A fine-tuned BERT classifier for fake news detection, wrapped in LIME so every prediction comes with the tokens that drove it. Paired with a data exploration notebook covering class balance, text length distribution and vocabulary overlap between real and fabricated articles.

Built because an accuracy number alone doesn't get a text classifier past review. Local attributions turn the model into something a domain expert can argue with.

Deep learning · Benchmark2023

Multi-Architecture Deep Learning for Music Genre Classification & Lyric Generation

A controlled comparison across architectures on multilingual song lyrics: basic RNN against LSTM, single- against multi-layer, embeddings learned from scratch against pre-trained vectors, and CNNs with mixed kernel sizes both standalone and as a feature extractor feeding an LSTM. The best classifier was then reused as a backbone for artist prediction via transfer learning.

Third task flips to generation: LSTM language models for lyrics, benchmarked against a classical n-gram baseline on perplexity — so the neural gain is measured, not assumed.

RAG · Ingestion pipeline2026

Document RAG Pipeline

The retrieval stack taken apart into its two halves: an ingestion notebook that loads and chunks source documents into a persisted Chroma vector store, and a second that assembles the full question-answering chain on top of it.

Splitting ingestion from serving is what makes a RAG system operable — you can re-index a corpus without touching the query path.

Cloud NLP service · Published2023–24

Accessibility Made Easy — Dyslexia-Friendly Documents

A cloud-hosted service that takes a Word document and reformats it for readers with dyslexia, applying evidence-based typography, spacing, layout and colour-contrast rules either automatically or under user control. Built with a four-person team; I led the NLP feature work, including automatic heading generation from frequency-based term salience, and owned deployment — secure upload and download, privacy-first architecture, and the production runtime.

500+ documents converted with 95% positive user feedback, and the work was published at EDULEARN24.

Telecom Customer Analytics — Star Schema & Churn Models

An Oracle star-schema warehouse for telecoms customer analytics: ETL from source tables, dimension and fact design, and analytical query patterns for customer value tiering, behaviour-change detection and revenue by call plan.
